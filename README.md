# 🎚️ HellTimer

> *"You suffer... but why?" — Napalm Death*

**HellTimer** — это бескомпромиссный, легковесный Pomodoro-таймер на C++, созданный для тех, чья работа превратилась в сущий ад, а продуктивность требует тяжелых решений. 

Каждые 25 минут ты выжигаешь задачи в котле дедлайнов, а звуковой движок оповещает тебя о короткой передышке в чистилище (или о начале нового круга страданий).

## 🛠️ Технологии ада
* **C++17** — быстрый как выстрел.
* **Dear ImGui + GLFW + OpenGL3** — минималистичный и брутальный интерфейс.
* **miniaudio** — изолированный аудиодвижок, который шепчет тебе прямо в наушники, когда пора отдохнуть.
